# Anthropic

В каталоге моделей выберите «Anthropic · Claude»:

- Base URL: `https://api.anthropic.com/v1`
- Имя модели: `claude-sonnet-4-6` (или доступная вашему ключу модель).
- Переменная с ключом: `ANTHROPIC_API_KEY`. Можно оставить `CLAUDE_API_KEY`, если ключ уже записан под этим именем.
- Формат: JSON по инструкции. Структуру и цитаты проверяет backend; нативные Structured Outputs пока не подключены.

Задайте ключ в `.env` в корне репозитория и перезапустите backend (и worker при JOB_MODE=celery). Ключ не передаётся в браузер. При выборе провайдера форма подставляет стандартное имя переменной: при необходимости измените его на существующее.

Проверка подключения вызывает GET `/models/{model}` без генерации. Анализ вызывает POST `/messages` с заголовками `x-api-key` и `anthropic-version: 2023-06-01`. Системные инструкции передаются отдельно; из ответа читаются только текстовые блоки. Обрезанные ответы и отказы не принимаются как оценка. Ограничения проекта на отправку данных внешним провайдерам сохраняются.

После добавления модели назначьте её нужным этапам в конфигурации агента. Изменение каталога само по себе не переключает существующие конфигурации.

API: https://platform.claude.com/docs/en/api/messages/create

В общей конфигурации этапов могут храниться и temperature, и top_p. Для Anthropic адаптер отдаёт приоритет temperature и не отправляет top_p. Фактически отправленные параметры сохраняются в журнале вызовов.
