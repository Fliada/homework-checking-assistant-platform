# Повтор временной ошибки

Реализуйте retry(operation, attempts, sleep): attempts — положительное целое число всех попыток. Повторять только TimeoutError. Перед повторами вызывать переданный sleep с задержками 1,2,4...; после последней ошибки не ждать, пробросить ошибку. Другие исключения пробрасываются сразу. Не используйте реальные ожидания внутри тестов.

Python 3.11, стандартная библиотека.
