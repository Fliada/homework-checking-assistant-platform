# Идемпотентное создание заказа

Реализуйте класс Orders с create(key,payload). Последовательные вызовы с тем же ключом и тем же payload возвращают одинаковый id без создания заказа. Повтор ключа с другим payload вызывает ValueError. Пустой ключ запрещён. Храните копию payload; внешние изменения не должны менять сохранённый заказ. Конкурентность в этом задании не требуется.

Python 3.11, стандартная библиотека.
