# Пагинация выдачи

Реализуйте paginate(items, page=1, limit=20): возвращайте dict items,total,page,limit; page и limit положительные целые, limit <=100, bool запрещён. Неверные значения вызывают ValueError. За пределами списка items пуст; исходный список не менять.

Python 3.11, стандартная библиотека.
