# Удаление дубликатов событий

Реализуйте deduplicate(events): список dict с id и version; для каждого id оставляйте событие с максимальной целой version. При равной версии выбирайте последнее; порядок id соответствует первому появлению. Отсутствие id/version или нецелая version вызывает ValueError. Не изменяйте вход.

Python 3.11, стандартная библиотека.
