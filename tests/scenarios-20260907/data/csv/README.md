# Агрегация CSV

Реализуйте summarize(text): CSV с заголовками category,amount, сумма Decimal по каждой категории. Пропускайте пустые строки, поддержите кавычки и запятые внутри category. Суммы возвращайте строками. Неверное число или отсутствие колонок вызывают ValueError.

Python 3.11, стандартная библиотека.
