# Нормализация адресов

Реализуйте slug(text): Unicode NFKC, нижний регистр, группы пробелов и пунктуации заменяются одним дефисом, буквы любого алфавита и цифры сохраняются. Краевые дефисы удаляются. Пустой ввод возвращает пустую строку. Нестроковый ввод вызывает TypeError.

Python 3.11, стандартная библиотека.
