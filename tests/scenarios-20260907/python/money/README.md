# Стоимость корзины

Реализуйте total(items): items — список пар (строковая цена, целое количество). Используйте Decimal, отклоняйте отрицательные/нечисловые цены, бесконечность и отрицательные количества через ValueError. Округляйте итог до копеек ROUND_HALF_UP и возвращайте строку с двумя знаками. Пустая корзина даёт 0.00.

Python 3.11, стандартная библиотека.
